Use this document in a **new, manually created chat attached to MaexSocial**. The old coordinator must have relinquished product coordination; reconcile that fact before mutation. No tool automatically creates this successor. `$maexsocial-orchestrator` is the Codex skill invocation, not a terminal command. If the fresh chat's catalogue does not expose it, explicitly ask it to read `.agents/skills/maexsocial-orchestrator/SKILL.md` from the verified repository root.
