Read [the charter](../../docs/00_PCF.md), the gate issue and its milestone. Verify each criterion against dated evidence and current dependencies. Record the owner’s decision, scope and unresolved criteria in [project status](../../docs/01_STATUS.md).

When the owner explicitly defers a gap, record it in an assigned issue with the target gate and a verifiable closure criterion for each gap. Add a native GitHub blocking dependency from that issue to G5 and to any earlier gate that needs the evidence. Verify the relationships on GitHub and link the tracker from the originating gate. The decision covers only the scope the owner accepted.

Before accepting or tagging G5, check all live GitHub blocking dependencies and each carried gap against its dated closure evidence. Keep G5 open and untagged if any blocker or carried gap is open, closure evidence is missing or dependency state cannot be verified. For every gate, create its annotated `gate-gN` tag only after the decision record merges, on that exact commit on main. Read back the remote tag, verify that it is annotated and resolves to the accepted commit, then record the result on the gate issue.
