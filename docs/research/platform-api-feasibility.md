# Platform API and MCP feasibility

[MS-005 / #5](https://github.com/Maeximilion/MaexSocial/issues/5) · G1 discovery · Public documentation checked **2026-11-05**. Google documents managed-location operations, Meta documents account-specific publishing, and TikTok requires creator control over Direct Post. Both media candidates document paid generation. None of these findings demonstrates that SocialEdge uses an endpoint or that MaexSocial has access to it.

## Evidence and claim coverage

The [MS-002 inventory](socialedge-feature-matrix.md) is the dependency for acceptance. Research began from [the 16-row checkpoint](https://github.com/Maeximilion/MaexSocial/blob/4f4df72b15a7d160b8744a925082996f93ef13ce/docs/research/socialedge-feature-matrix.md) and was checked at dc6a3fa, then reconciled against [M01–M17 at 191df84](https://github.com/Maeximilion/MaexSocial/blob/191df84b4f78c1673b52a99b1a5ce852ae341676/docs/research/socialedge-feature-matrix.md). [Issue #40](https://github.com/Maeximilion/MaexSocial/issues/40) and the [media workflow](../18_MEDIA_LIBRARY.md) describe proposed MaexSocial features separately from that inventory.

Method: read public provider references, policies, price tables and provider-authored collections. Source dates throughout are **access dates**. The Meta web reader returned HTTP 429 for several guides. Direct unauthenticated GETs to the English documentation returned readable content. To reproduce, open the linked guide with `?locale=en_US` and inspect its permissions, limitations or status section. No account connection, app submission, MCP session, paid job, upload, publication or ad spend was tested. Fallbacks and operating controls below are proposed behavior.

## Google Business Profile

**Common access and cost.** An approved Cloud project and owner/manager access to the intended business are separate requirements. The access application calls for a verified profile active for at least 60 days and a business website. The OAuth scope for the operations below is `https://www.googleapis.com/auth/business.manage`. Google lists the API at no charge for registered users. The quota table lists 300 QPM defaults for several named APIs and 10 edits/minute/profile for Business Information. A zero quota requires access approval. Check the actual API/project quota before promising throughput, particularly for legacy v4 methods. Storage, Pub/Sub and supplier costs are separate and unpriced here. [Prerequisites](https://developers.google.com/my-business/content/prereqs) · [Limits](https://developers.google.com/my-business/content/limits) · [Pricing](https://developers.google.com/my-business/content/pricing)

| Claim / API | Documented operation and success evidence | Restriction and fallback |
|---|---|---|
| M02 · Business Information and Verifications v1, media v4 | Find an existing location before creation. Read/update supported fields, submit media, request eligible verification options and track the verification state. An API resource ID confirms creation only. | Owner must directly request verification. Hold duplicate or disputed locations for the owner. Unsupported catalogue fields, reinstatement and acceptance of submitted photos require separate checks. [Locations](https://developers.google.com/my-business/content/location-data) · [Verification](https://developers.google.com/my-business/content/manage-verification) · [Media methods](https://developers.google.com/my-business/reference/rest/v4/accounts.locations.media) |

Only `LIVE` denotes publication. `PROCESSING` and `REJECTED` are distinct. | Check location eligibility and content policy. Schedule an approved revision locally if policy permits. Reconcile an uncertain create before retry, otherwise return the draft for manual posting. | M05 · reviews v4 and Notifications v1 | A verified location can list reviews and update/delete the business's reply. New/updated review events can arrive via a configured Pub/Sub topic. Read the review and its reply after a write. | A reply requires the customer's specific authorization. Reply deletion does not remove the review. Escalate a disputed review to Google's reporting process. [Reviews](https://developers.google.com/my-business/reference/rest/v4/accounts.locations.reviews/updateReply) · [Notifications](https://developers.google.com/my-business/content/notification-setup) |
| M01, M03, M12 · Performance v1 | Read daily metrics such as calls clicked, website clicks and direction requests, plus monthly search-keyword impressions. | Report the requested interval, metric and last available day. [Performance API](https://developers.google.com/my-business/reference/performance/rest) · [Metrics](https://developers.google.com/my-business/reference/performance/rest/v1/DailyMetric) |

**Policy and lifecycle.** Google requires prior, specific, express consent for automated actions. Agencies/end clients using GBP programmatically need their own project. A tool provider cannot give them indirect scripted access via its approved project. Distinguish provider-operated actions from a customer automation surface and establish a permissible project model before scheduling. Limited caching is allowed for performance only, securely, for at most 30 calendar days and without manipulating or aggregating cached content. Provide disassociation within seven business days of notice. If the intended model conflicts with these limits, offer drafts and a manual manager workflow. [Third-party, automated use and storage policies](https://developers.google.com/my-business/content/policies)

## TikTok Content Posting API v2

| M16 route | Authority, operation and caps | Confirmation and fallback |
|---|---|---|
