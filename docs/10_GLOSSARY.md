# Glossary

| Term | Meaning in MaexSocial |
|---|---|
| Gate | A stage decision supported by explicit acceptance evidence |
| Task | A stable MS-NNN work package with dependencies and a definition of done |
| Vertical slice | A complete user workflow through the necessary layers |
| REA | Reverse Engineer Anything, the analysis skill and tool suite |
| Evidence | A dated observation or artifact supporting a specific claim |
| Static analysis | Inspection of supplied code/artifacts without observing their execution |
| Runtime observation | Behavior actually observed during a declared scenario |
| Provider | An external platform or generation service |
| MCP | A tool protocol, whose server exposes specific operations and access boundaries |
| Publication intent | Durable instruction to publish an exact revision to an authorized account |
| Reconciliation | Finding an external operation's true outcome after uncertainty |
| Bounded autonomy | Authority to act within approved account, content, schedule and budget limits |
| Project | The single GitHub Project for MaexSocial, with multiple views |
| Iteration | A planning period, not evidence of completion |
